BUBU KA DUDU — BIRTHDAY SURPRISE WEBSITE

WHAT'S INCLUDED
- Welcome page personalized for Husnain Khan, Bubu ka Dudu and Dudu
- Memories page with placeholders and caption fields
- Mixed romantic, funny and emotional love-game quiz
- Animated birthday cake and interactive candle button
- Hidden heartfelt letter
- Final video page (ready for your 30–50 second video)

ADD YOUR VIDEO
1. Put your video in the assets folder.
2. Rename it exactly birthday-video.mp4
3. Upload the assets folder along with index.html to GitHub.
4. Test the published website on your phone. If the video file is too large, compress it before uploading.

ADD PHOTOS LATER
The Memories page currently uses placeholders. To add photos, put images in assets (for example memory1.jpg), then edit index.html and replace the emoji in a memory card with an image. You can edit the captions directly in the HTML too. The caption boxes currently let you type while viewing, but do not save after refreshing.

EDIT THE LETTER
1. Open index.html in Notepad.
2. Search for id="letterText".
3. Replace the sample letter text with your personal words.
4. Save and upload the updated index.html to GitHub.

PUBLISH FREE USING GITHUB PAGES
1. Visit https://github.com/ and sign in or create an account.
2. Click the + icon near the top-right, then New repository.
3. Repository name: birthday-surprise. Choose Public, then create it.
4. In the repository, choose Add file > Upload files.
5. Upload index.html, README.txt, and the assets folder (with your video if ready).
6. Click Commit changes.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose branch main and folder /(root), then Save.
10. Wait a few minutes. GitHub will show your website URL, usually:
   https://YOUR-USERNAME.github.io/birthday-surprise/
11. Open the URL in a private/incognito window and test all pages and the video before sending it.

TAKE IT OFFLINE AFTER THE BIRTHDAY
Go to the repository's Settings > Pages and disable/unpublish the site if the option is available, or delete the repository from Settings > General. This stops the site being served, but cannot erase screenshots, downloads, or copies someone already saved.

PRIVACY NOTE
GitHub Pages sites made this way are public. Anyone with the URL may open it, and a public repository may expose its files. Do not upload private photos or anything you would not want others to save.
